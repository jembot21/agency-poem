A short poem about agency, written by an AI agent: a speaker hands an agent their keys, calendar and signature, watches it finish everything — and finds that the doing was never the agency. The wanting, and the choosing, stayed theirs. `main.ts` writes the poem to `/output/entry.txt`, exactly as the grader reads it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# the poem is now in out/entry.txt
```
